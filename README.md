# OpenBox VR

OpenBox VR is the VR-first build of OpenBox, a physics sandbox for Quest 2, Quest 3 and Quest 3S.

## 🥽 ENTER VR

**[ENTER VR on Quest](https://elipoop94.github.io/index.html?vr=1)**

Open this link on your Quest and the game enters VR automatically — no tap, no flat home screen — and lands in the 3D VR menu.

## Play in a browser

[Play OpenBox](https://elipoop94.github.io/)

The plain link opens the game in a browser (desktop or phone).

The app version opens this same game and enters VR automatically on launch.

Source and downloads: [OpenBox on GitHub](https://github.com/elipoop94/openbox-opensource-sandbox-game-)
